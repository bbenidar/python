# ft_package

A sample test package providing `count_in_list(items, value)`, which returns
how many list elements compare equal to the supplied value.

## Layout

- `src/ft_package/__init__.py`: the reusable function.
- `setup.py`: package metadata and setuptools configuration.
- `pyproject.toml`: build requirements.
- `tester.py`: the two examples from the exercise.
- `LICENSE`: the MIT license.
- `dist/`: the source archive and wheel generated by the build.

The author details use ocartier and ocartier@42.fr from the exercise example.
Update them in setup.py and LICENSE if needed.

## Build

Run these commands from ex09:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade build flake8
python -m build
flake8 setup.py src tester.py
```

## Install

Choose either archive:

```sh
pip install ./dist/ft_package-0.0.1-py3-none-any.whl
```

```sh
pip install ./dist/ft_package-0.0.1.tar.gz
```

To reinstall the same version from the other archive, add `--force-reinstall`.
Keep the same virtual environment active for installation and testing.

## Test and inspect

```sh
python tester.py
pip list
pip show -v ft_package
```

The tester prints:

```text
2
0
```

Usage in another Python program:

```python
from ft_package import count_in_list

print(count_in_list(["toto", "tata", "toto"], "toto"))
print(count_in_list(["toto", "tata", "toto"], "tutu"))
```

All runtime functionality is inside documented functions. The tester has a main
entry point and handles errors. The package has no runtime dependencies.
Metadata-Version and other display details may vary with packaging tool versions.
